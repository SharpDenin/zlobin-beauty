# Запись

Клиент записывается с публичной страницы мастера. Мастер и салон видят ту же запись в списке и в календаре.

## Создание

1. Выбрать мастера (поиск по городу или прямая ссылка).
2. Выбрать услугу. Гибкая запись и фиксированное окно — разные шаги дальше.
3. **Гибкая:** ближайшие рабочие дни → свободное время → итог → «Подтвердить запись».
4. **Фиксированное окно:** список сеансов с числом мест. Нет мест — «Нет доступных сеансов».
5. Несколько услуг в одном визите: «Добавить вторую услугу», если услуги совместимы и есть организация мастера.

Кто записывается, видно мастеру (имя клиента, не внутренний идентификатор).

## Длительность

**Продолжительность записи задаёт услуга** (`duration_minutes`) в момент создания.

Перенос в календаре меняет **начало**. Сервер принимает новое `starts_at`. Хвост события в сетке не становится новым правилом длительности визита. Менять длительность имеет смысл у блоков планировщика (личные задачи и перерывы), не у клиентской записи.

Фиксированное окно привязано к сеансу: его нельзя перетащить.

## Дата и время

- Чипы дат показывают рабочие дни вперёд (выходные в чипах не предлагаются; календарное поле «или выберите день» остаётся).
- Слоты считаются: рабочие часы минус занятость.
- Прошедшее время создать нельзя.
- Черновик формы на публичной странице не обязан переживать полную перезагрузку; шаг назад внутри визарда поля сохраняет.

## Подтверждение и статусы

| Статус | Как видит пользователь |
| --- | --- |
| Ожидает подтверждения | Запись ушла мастеру |
| Подтверждена | Можно приходить; можно перенести, если правило позволяет |
| В процессе | Приём начат |
| Завершена | Визит закрыт |
| Отменена клиентом / мастером / салоном | Конечный статус |
| Клиент не пришёл | Конечный статус |

Автоподтверждение зависит от настроек мастера/салона. В демо у Анны клиент `client1` подтверждается сразу.

## Конфликты

Пересечение по времени на того же мастера сервер отвергает (ограничение в booking). Календарь откатывает перенос. Повторная отправка кнопки блокируется (`Создаём…`, идемпотентный ключ на создании).

Чёрный список мастера и заблокированный аккаунт — запись не создаётся, текст ошибки человеческий.

## Перенос

- С календаря (drag) или из карточки записи.
- Нельзя для завершённых, отменённых и фиксированных окон.
- Клиент переносит свою будущую запись там, где API это разрешает.

## Кто с кем связан

Запись связывает клиента, мастера (и салон, если мастер в организации). Сообщение из карточки открывает существующий диалог, не плодит второй.
