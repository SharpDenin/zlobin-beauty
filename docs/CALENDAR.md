# Календарь

Экран `/calendar`. На телефоне (≤599 px) режим **День** — компактный список слотов `CalendarMobile` (референс «Расписание»); **Месяц** — сетка точек того же компонента. **3 дня**, **Список** и широкие экраны используют FullCalendar 6.

## Виды

| Вид | Где | Заметка |
| --- | --- | --- |
| День | Телефон | Горизонтальная лента дат + вертикальный список слотов по рабочему графику |
| День | Планшет / десктоп | FullCalendar timeGrid |
| 3 дня | Телефон / узкий | FullCalendar вместо недели |
| Неделя | Планшет и десктоп | Колонки времени |
| Месяц | Телефон | Сетка точек `CalendarMobile`; тап открывает день |
| Месяц | Широкий | FullCalendar dayGrid |
| Список | Все | Лента событий за период |

Сохранённый вид: preference `calendar.view.desktop` / `calendar.view.mobile` / `calendar.view.embedded`. При смене ширины неделя ↔ 3 дня подменяется.

## Мобильный день (референс)

- Заголовок «Расписание», кнопка выбора даты (native date picker), «Сегодня».
- Лента дней: выбранный день — фиолетовая плашка (`--color-primary` / `#7C82FF`); сегодня отличим.
- Слоты строятся из **рабочего графика** мастера (недели + исключения), шаг 30 минут. Вне графика свободные фиолетовые слоты не показываются.
- Свободный слот — фиолетовая плашка времени и переход к созданию.
- Занятый интервал — приглушённое время; в начале события карточка; продолжение — подпись «Занято».
- Тап / long press: карточка события или меню создания; long press 500 ms, срыв при сдвиге > 16 px.

## Рабочие часы

Часы мастера (обычно пн–пт 10:00–19:00 в демо). На широкой сетке FullCalendar открывается в **диапазоне отображения** (по умолчанию 08:00–22:00, минимум 4 часа, шаг 30 минут). События раньше или позже не пропадают: диапазон расширяется.

Создание слота вне рабочих часов при открытии формы подтягивается к началу рабочего окна, если часы известны.

## Записи и задачи

- Запись клиента — из booking, цвет системный, **нельзя перекрасить**.
- Задачи / перерывы / блокировки — `planner_blocks`, цвет из палитры. Цвет сохраняется в профиле.
- Фиксированное окно записи нельзя перетащить.
- Задачи не смешиваются с записями; на доступность слотов клиента влияют через backend `FreeSlots` (блоки планировщика учитываются).

## Перенос и размер

- Запись со статусом «ожидает» или «подтверждена» и режимом гибкой записи можно **перетащить** на широкой сетке. Уходит `reschedule` с новым началом. **Длительность остаётся длительностью услуги**.
- На мобильном дне-списке перенос — через карточку / диалог переноса (без drag сетки).
- Завершённые, отменённые, неявка — не двигаются.
- Блоки планировщика на FC можно двигать и менять длительность (шаг 15 минут).
- При конфликте сервер отклоняет изменение, сетка откатывается, показывается русская ошибка.

## Жесты

| Жест | Порог | Поведение |
| --- | --- | --- |
| Long press | **500 ms** | Меню пустой области / настройки задачи |
| Срыв long press | сдвиг **> 16 px** | Таймер сбрасывается |
| Вертикальный скролл | `touch-action: pan-y` | Список слотов скроллится без смены даты |
| Горизонтальный swipe | `detectHorizontalSwipe` (порог 56 px) | Смена дня / периода при режиме «Свайпом» |
| Drag / resize | FullCalendar | Не на мобильном day-list |

## Роли

- Владелец / администратор салона — календарь организации, фильтр мастера.
- Мастер салона и частный мастер — свой календарь (`/v1/appointments/mine`).
- Клиент не видит этот экран; выбор времени — публичная страница мастера и `GET /v1/masters/{id}/slots`.

## Прочее

- Индикатор «сейчас» и отметка сегодняшнего дня.
- Пустой / выходной день — понястое состояние, не техническая ошибка.
- Нижняя навигация: отступ снизу у списка слотов (`--nav-h`, safe-area).
- Часовой пояс салона используется для сетки; пользователю IANA-строку не показываем.

## Связь с записью

Слоты на публичной странице мастера считаются на сервере из тех же рабочих часов и занятости (`FreeSlots`). Календарь — рабочее место мастера/салона, не мастер-визард клиента.
