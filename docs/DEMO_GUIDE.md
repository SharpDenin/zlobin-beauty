Перед показом:

```bash
docker compose up -d
curl -fsS http://127.0.0.1:8090/healthz
# при пустой базе:
docker compose --profile seed run --rm seed
```

UI: http://127.0.0.1:5173 (локально) или `PUBLIC_APP_URL`.

## Рекомендуемый сценарий (~15 минут)

1. Войти как владелец (`master1@demo.local`).
2. Старт: название салона, выручка / загрузка / число записей **сегодня**, список на дату.
3. Открыть день в ленте, затем **Расписание**.
4. Показать запись в сетке или списке, открыть карточку (имя клиента, услуга, статус).
5. **Контакты** → Екатерина → «Написать» — тот же чат при втором нажатии.
6. Коротко **Сообщения**.
7. **Команда** → «Создать QR» → ссылка `/invite/…`. Не обязательно регистрировать нового человека на сцене.
8. Выйти. На `/login` нет текста «Сессия завершилась».
9. Войти как клиент (`client1@demo.local`).
10. **Мастера**, город Красноярск → Анна Волкова.
11. Услуга «Стрижка» → ближайший будний день → время → подтвердить.
12. Экран «Запись отправлена».
13. Выйти. Войти как поставщик (`supplier1@demo.local`).
14. **База знаний** — открыть статью.
15. **Товары** — каталог без технических идентификаторов.

Если слотов на сегодня нет — взять следующий будний в чипах. Выходные в чипах не предлагаются.
