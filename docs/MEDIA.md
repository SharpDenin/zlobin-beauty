# Медиа

Один контур: `POST /v1/media` + выдача `/v1/media/{id}/content`. Компоненты: `MediaDropzone`, `MediaImage`, `MediaVideo`.

## Где используется

| Место | Purpose |
| --- | --- |
| Аватар / фото мастера | `profile` |
| Фото салона / логотип | `salon` |
| Портфолио | `portfolio` |
| Фото услуги | `service` |
| Товар каталога | `product` |
| Обложка статьи | `article` |
| Видео в материалах | `video` |
| Вложение в чат | `message` |
| Фото до/после визита | `before_after` |
| Накладная / документ | `document` |
| Доставка | `delivery` |

## Проверка файла

1. Заголовок читается с диска запроса; MIME из браузера — только подсказка.
2. Magic bytes: JPEG, PNG, GIF, WEBP, PDF, MP4, WebM, QuickTime. HEIC отклоняется.
3. Заявленный тип должен быть совместим с детектированным.
4. Purpose ограничивает тип (GIF — портфолио/чат/статья/услуга; видео — video/message/portfolio; PDF — document).
5. Картинка (JPEG/PNG/GIF) должна декодироваться; слишком большие стороны отклоняются.
6. Потолок: **10 МиБ** для обычных файлов, **50 МиБ** для видео. Шлюз и multipart режут тело по видео-потолку.

Ошибки в UI: «формат не поддерживается», «файл слишком большой» (с размером), «файл повреждён» — без английского сырого текста.

## Доступ

- Загрузка: авторизованный пользователь, лимит частоты.
- Удаление: только владелец (`owner_user_id`).
- Публичное чтение: `profile`, `salon`, `portfolio`, `product`, `article`, `video`, `service`.

**Публичное чтение портфолио, аватара, фото салона, товара, статьи и услуги — намеренное поведение витрины. Это не IDOR.**

- `message` — участник беседы (проверка через communications).
- `before_after` — участник записи (проверка через booking).
- `document` / `delivery` — не публичные.

Картинка на странице не получает bearer: короткий подписанный URL (`/url`, TTL 15 минут).

## Хранение

MinIO. Ключ `purpose/userId/id.ext`, не исходное имя файла. Имя клиента чистится от управляющих символов и в объект не попадает.
