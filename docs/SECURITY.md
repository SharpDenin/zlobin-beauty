# Security

Документ по фактическим проверкам и коду. Скрытие UI не считается контролем доступа.

## Authentication

- Access JWT + refresh. Сессия в `zb.auth`.
- Просроченный JWT: выход и **один** показ «Сессия завершилась. Войдите снова.»
- Обычный `/login` и повторный вход после logout этого текста не содержат.
- Logout вызывает `/v1/auth/logout` и чистит хранилище.
- Во frontend-бандле нет JWT secret и internal token.

## Authorization

Проверка в сервисе: владелец, членство в организации, участник записи/диалога.

Клиент не читает календарь салона. Поставщик не читает записи салона. Мастер не правит чужое портфолио и не удаляет чужие контакты.

## IDOR — проверенные ресурсы

Проверено запросами к API (Playwright `e2e/security.spec.ts` и разбор кода), не «кнопка скрыта»:

| Ресурс | Ожидание при чужом id / чужой org |
| --- | --- |
| Календарь организации | 403 |
| Запись (чтение, отмена) | 403/404 |
| Портфолио (правка, удаление) | 403/404 |
| Блок планировщика | 403/404 |
| Контакт | 403/404 |
| Медиа DELETE | 403/404 |
| Приглашения салона | 403 |
| Статья (правка, снять с публикации) | 403/404 |
| Заказ поставщику / заказ магазина | 403/404 |
| `/v1/internal/*` с браузера | **404** (нет маршрута на gateway) |

## Gateway

Внутренние маршруты сервисов не публикуются. Токен `INTERNAL_TOKEN` только S2S.

## CORS

`CORS_ORIGINS` — список origin. `APP_ENV=production` + `CORS_ORIGINS=*` → процесс не стартует. Локальный default: `http://localhost:5173,http://127.0.0.1:5173`.

## Upload

См. [MEDIA.md](MEDIA.md): magic bytes, размер, purpose, удаление только владельцем.

## Moderation

Пакет `backend/shared/moderation` на сервере. Запрещённые формулировки режутся в предусмотренных пользовательских полях (портфолио, чат, заметка контакта, заголовок схемы визита и др.). Обход через API без UI не проходит.

## Secrets

Не класть в репозиторий и не вшивать во frontend:

- `JWT_SECRET`, `INTERNAL_TOKEN`
- пароли Postgres и MinIO
- пароли реальных пользователей

Demo-пароль стенда — только для seed, см. [DEMO_GUIDE.md](DEMO_GUIDE.md).

Production-сборка SPA: `VITE_API_BASE_URL` пустой — запросы идут на `/v1` того же origin. Vite **отказывается** собирать production, если в `VITE_API_BASE_URL` попали `localhost` или `127.0.0.1` (защита от случайного bake-in из локальной оболочки).

## Production requirements

Перед боем:

- `APP_ENV=production`
- уникальный `JWT_SECRET` (≥ 32, не dev-строка)
- уникальный `INTERNAL_TOKEN` (≥ 16, не `dev-internal-token`)
- пароль Postgres ≠ `postgres`, длина ≥ 12
- MinIO не `minioadmin` / короткий пароль
- `ALLOW_DEV_BILLING=false`
- явный `CORS_ORIGINS` без `*`
- toolchain **Go 1.26.6+** (закрывает stdlib-находки govulncheck на 1.26.5)

Проверка: `backend/shared/config/production.go`.
