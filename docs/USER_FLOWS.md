# Сценарии

Человеческие шаги. Внутренние пути API и идентификаторы в тексте для пользователя не используются.

Снимки экранов: [SCREENSHOTS.md](SCREENSHOTS.md).

## Владелец салона

1. Вход (email + пароль).
2. Открывается **старт** — название салона, цифры дня, список записей на дату.
3. **Расписание** — день салона: записи мастеров, задачи, перерывы.
4. Карточка записи — кто, услуга, статус, «Написать», перенос, начать приём.
5. **Контакты** — поиск человека → карточка → «Написать» (повторно тот же диалог, не дубль).
6. **Сообщения** — переписка и вложения.
7. **Команда** → «Создать QR» → ссылка приглашения. Мастер регистрируется по ссылке и сразу в салоне.
8. **Салон / настройки** — данные точки, политика контактов, график.

Пустые дни: «На этот день записей нет». Ошибка сети — русская плашка, не технический дамп.

## Мастер

1. Вход. Частный мастер попадает на свой обзор / профиль, сотрудник — в контур салона.
2. **Профиль** — имя, город, фото, типы профессий (несколько галочек).
3. **Типы** нельзя снять, если уже стоят на услугах или записях — система объяснит это простым текстом.
4. **Календарь** и **график** (часы пн–пт и исключения).
5. **Портфолио** — добавить работу, подпись, категория; сетка на публичной странице.
6. Клиенты записываются с публичной страницы; мастер подтверждает или видит автоподтверждение.
7. **Сообщения** с клиентом из записи или контактов.

Регистрация без салона допустима: выбран тип профессии, салон не обязателен.

## Клиент

1. Вход.
2. **Мастера** — город по умолчанию Красноярск, при необходимости «показывать из других городов».
3. Карточка мастера: фото, услуги, портфолио.
4. **Услуга** → **дата** (ближайшие рабочие дни) → **время** → **итог**.
5. «Подтвердить запись». Успех: «Запись отправлена» / «подтверждена автоматически».
6. Вторая услуга в том же визите — «Добавить вторую услугу», если мастер и салон это позволяют.
7. **Мои записи** — статус и перенос/отмена там, где разрешено.

Фиксированное окно (мастер-класс): вместо сетки слотов — список сеансов с числом мест. Если окон нет: «Нет доступных сеансов».

## Поставщик

1. Вход → домашняя страница поставщика.
2. **База знаний** — поиск, статья, редактор (для своих материалов).
3. **Товары** — каталог, карточка, наличие.
4. Со стороны мастера: косметика → поставщик → в корзину → филиал получения → подтверждение заказа.
5. Поставщик видит заказ и проводит статусы со своей стороны.

## Неавторизованный и протухшая сессия

- `/login` без предыдущей сессии — без пугающего текста про истечение.
- Просроченный сохранённый вход — один раз «Сессия завершилась. Войдите снова.»
- Повторный вход после выхода — снова чистая форма.
