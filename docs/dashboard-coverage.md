# Покрытие панелей макетами (`макеты/`)

Источник: 12 досок (photo_1 … photo_12). Сопоставление с текущим кодом на 2026-08-05.

Легенда статусов: **готово** · **частично готово** · **не реализовано** · **требуется уточнение**

## Правило рекомендаций (клиентская главная)

Пока нет ML-модели, рекомендованные мастера сортируются так:

1. соответствие выбранной / популярной категории услуги (если задана);
2. наличие свободного слота в ближайшие 7 дней;
3. рейтинг (`rating_avg`);
4. число завершённых посещений мастера (агрегат из booking/clients событий);
5. расстояние — только при наличии координат клиента и филиала;
6. стабильный тай-брейк по `master.id`.

Зафиксировано также в `docs/architecture.md` (раздел рекомендаций будет добавлен при выносе в marketplace API).

## Доска 1 — Клиент: поиск и запись

| Экран | Роль | Назначение | Данные | Действия | Фильтры | Показатели → источник | Сервис | Статус |
|-------|------|------------|--------|----------|---------|----------------------|--------|--------|
| Главная клиента | client | Discovery | город, поиск, категории, промо, мастера, услуги | поиск, избранное, запись | город | рекомендованные мастера → marketplace+booking; популярные услуги → marketplace агрегаты | marketplace, booking | частично готово |
| Поиск / фильтры | client | Отбор | мастера, цены, рейтинг | показать результаты | город, категория, цена, слоты, рейтинг, портфолио, дистанция | счётчик результатов → count API | marketplace, booking | частично готово |
| Карточка мастера | client | Выбор | фото, био, услуги, портфолио, слоты, отзывы | избранное, связь, запись | — | рейтинг/число отзывов → communications reviews | marketplace, booking, communications | частично готово |
| Дата и время | client | Слот | календарь, слоты | выбрать время | дата | свободные слоты → booking FreeSlots | booking | готово |
